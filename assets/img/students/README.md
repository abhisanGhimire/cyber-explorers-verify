# Student photos go here

Save each student's photo as `<certificate-id>.jpg` (or `.png`), for example:

```
CE-2026-014.jpg
```

Then set `"photo": "assets/img/students/CE-2026-014.jpg"` in `data/students.json`.

Photos are optional — if a student doesn't have one, leave `"photo": ""` and a friendly
placeholder avatar will be shown instead.

**Before adding a photo, make sure you have permission** (a signed media/photo release from
the teen and their parent/guardian, per your Club's standard policy) — this repository is
public on GitHub, so anything committed here is publicly visible.
