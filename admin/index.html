Add a Student

This tool runs entirely in your browser — nothing is uploaded anywhere. It just helps you build the JSON entry and the certificate's QR code. You still commit the result to the repo yourself. See README.md for the full step-by-step.

Before you start: if this student has a photo, save it as assets/img/students/<certificate-id>.jpg in the repo first (see assets/img/students/README.md). Get a signed photo release if your Club requires one.
